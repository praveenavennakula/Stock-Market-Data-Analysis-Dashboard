# 📈 Stock Market Data Analysis Dashboard

## About This Project

In this project, I stepped into the role of a Data Analyst working for a startup investment firm. The goal was to gather and analyze financial data from different sources to better understand how companies perform and how their stock prices relate to their revenue growth.

Using Python, data analysis libraries, and web scraping techniques, I collected historical stock price data and quarterly revenue information, then transformed the data into interactive visualizations that make trends and patterns easier to explore.

## Companies Analyzed

This project focuses on:

* Tesla
* Amazon
* AMD
* GameStop

## What I Did

* Collected historical stock market data using Python.
* Extracted quarterly revenue data through web scraping.
* Cleaned and organized the datasets for analysis.
* Explored trends between company revenue and stock performance.
* Created interactive visualizations using Plotly.
* Built a dashboard to present key insights in a clear and engaging way.

## Dashboard Highlights

The dashboard allows users to:

* View stock price trends over time.
* Compare revenue growth with stock performance.
* Identify patterns and potential relationships in the data.
* Explore interactive charts for a better understanding of each company's performance.

## Tools & Technologies

## Key Takeaways

This project provided practical experience in:

* Data collection and web scraping
* Data cleaning and preparation
* Financial data analysis

Overall, this project demonstrates how data from multiple sources can be combined and visualized to support more informed investment decisions and uncover valuable business insights. 🚀
